# Security Policy

## Supported Versions

Security fixes apply to the latest released version (`0.3.0`) on `main`.

## Security Design

- No credentials or secret values are stored in repository files or printed by readiness checks.
- Paid or mutating operations require explicit confirmation flags.

## Reporting a Vulnerability

Please report suspected security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/avalonreset/legends-grant/security/advisories/new) rather than opening a public issue. Include reproduction steps and affected versions.

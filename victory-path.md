# victory path

The organized way a user goes from "I need funding" to money or a clean
no with reasons. Seven steps, each with a receipt. Skip none.

1. MAP: vault business note to `profiles/<slug>.md` (`vault-map.md`).
   Receipt: filled profile with vault citations + Updated date.
2. SWEEP: Tier 1 APIs, then state file, then private rolling (`find.md`).
   Receipt: ranked shortlist with scores (`match.md`).
3. GATE: eligibility verdict per top candidate (`qualify.md`).
   Receipt: eligible / likely + open question / out + notice quote.
4. NOTE: one opportunity note per real candidate.
   Receipt: note with source URL + retrieved date + channel + next action.
5. BUILD: package per `apply.md` (narrative, budget, attachments).
   Receipt: complete draft the owner has reviewed.
6. SEND: one authorized send per `submit-lanes.md`.
   Receipt: confirmation page, email ack, or tracking number.
7. TRACK: award window, reporting duties, next check date in the note.
   Receipt: date set, owner knows what happens next.

A run that ends at step 3 with honest OUTs is still a victory: it spent
an hour, not six weeks, and the notes stay warm for the next round.

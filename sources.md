# sources

The current researched registry is [grant_engine/data/us-sources.json](grant_engine/data/us-sources.json).
See [coverage](docs/COVERAGE.md) for jurisdictions, implemented adapters and gaps,
and [source research](docs/SOURCE-RESEARCH.md) for APIs, directories and private
data suppliers. Source access and program terms can change after verification.

Source categories are not a priority order. Select them by applicant, project
geography, beneficiaries, purpose and financial constraints.

Public discovery currently runs through Grants.gov and four vetted third-party
CommonGrants state feeds. All other entries are researched routes for an agent
to investigate, not implemented collectors. No commercial subscription or
Alexandria dependency is selected.

Always distinguish official opportunity notices, third-party aggregations,
program directories, award history and procurement. Use the first for final
terms; the others can identify leads. Historical `federal.md`, `states/` and
`private-rolling.md` remain dated background, not proof of today's availability.

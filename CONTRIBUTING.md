# Contributing to `legends-grant`

Contributions are welcome. Keep changes focused, offline-testable, and explicit about user boundaries.

## Development Workflow

1. Run the existing unit and contract tests before and after your changes.
2. Do not add network calls, paid provider calls, or external mutations to default read-only commands.
3. Keep `skills/cto-legends/SKILL.md` byte-exact with the canonical `cto-legends` router skill.
4. Do not use em dashes in documentation, comments, or release notes.
